1. Acerca de ARCA Fast

ARCA Fast es una extensión de Google Chrome diseñada para facilitar la búsqueda de clientes y la consulta de sus números de CUIT en tareas administrativas y contables.

2. Información incluida en la extensión

La extensión incorpora una base de datos local que puede contener nombres o razones sociales y números de CUIT de clientes. Esta información se utiliza únicamente para permitir la búsqueda y visualización de los registros dentro de la extensión.

3. Datos recopilados del usuario

ARCA Fast no solicita ni recopila datos personales del usuario de la extensión, como nombre, correo electrónico, contraseñas, ubicación, historial de navegación o comunicaciones personales. La extensión no utiliza herramientas de publicidad, seguimiento ni analítica.

4. Almacenamiento y funcionamiento

La base de clientes se encuentra incluida en los archivos de la extensión y se consulta localmente en el navegador. Las búsquedas se procesan en el dispositivo del usuario. La extensión no transmite las búsquedas ni la base de clientes a servidores externos.

5. Portapapeles

Cuando el usuario selecciona un cliente, ARCA Fast copia el CUIT correspondiente al portapapeles para facilitar su uso. La extensión no lee el contenido previo del portapapeles.

6. Uso y divulgación

La información incluida en la base se utiliza para la finalidad funcional de la extensión: buscar clientes y consultar sus CUIT. ARCA Fast no vende ni comparte esa información con terceros, ni la utiliza para publicidad, elaboración de perfiles comerciales, evaluación crediticia o concesión de préstamos.

7. Cambios en esta política

Esta política podrá actualizarse si cambian las funciones de ARCA Fast o las prácticas de tratamiento de información. La versión vigente estará publicada en esta misma dirección.

8. Contacto

Para consultas sobre esta política o sobre la privacidad de ARCA Fast, contactá al responsable mediante el correo indicado al comienzo de este documento.
